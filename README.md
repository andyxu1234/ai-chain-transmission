## 🎯 它回答什么问题

不是"美股涨 A股就涨"这种废话，而是：

- **隔夜美股哪个环节在动？** 拆成 8 个环节分别看，而不是笼统看"AI 板块"
- **A股同环节历史上跟涨/跟跌多少？** 用滚动 20 日回归算出的传导系数 β，并给出 R² 可信度
- **今天的传导信号是强是弱？** 分强/中/弱/失效四档，而非无条件预测
- **哪些标的值得盯？** 环节内按历史跟随意愿排序
- **昨天猜对了没有？** T+1 实测验证，命中率逐日累积

## 🧮 方法论

**传导系数 β** —— 对每个环节，取最近 20 个配对交易日：

```
x = 美股该环节当日加权涨跌（隔夜）
y = A股该环节次日超额涨跌（已剥离大盘）
β = 回归斜率      R² = 可信度
```

三个必须处理的失真：

| 失真 | 后果 | 处理 |
|---|---|---|
| **大盘污染** | A股环节涨跌主要跟着沪深300走，测出的是"大盘同步性"而非产业链传导 | y 先减去同期沪深300涨跌，做超额收益回归 |
| **涨跌停/停牌** | 均值被极值带偏 | 用中位数、剔除无效样本 |
| **传导会失效** | 政策/汇率/北向资金打断传导 | 输出强度评级（强/中/弱/失效），不做无条件预测 |

**T+1 验证** —— 每日记录预判方向，收盘后用实际涨跌回验，滚动统计命中率，并据此校准 β。
